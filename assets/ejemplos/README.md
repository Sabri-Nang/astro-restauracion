# Imágenes de ejemplo

Esta carpeta está reservada para imágenes astronómicas con permiso de uso.
Todavía no se incorporaron imágenes.

Antes de agregar una imagen, documentar aquí:

- Nombre del archivo y descripción.
- Fuente y enlace de origen.
- Autoría, licencia o permiso y atribución requerida.
- Modificaciones realizadas, si corresponde.

No presentar imágenes generadas como observaciones astronómicas reales.
